说明： kind 是自由文本——预设有常用类型，也可选「自定义…」自由填写（Nginx / Harbor / Vault / LDAP / K8s…）。
URL 三字段 + 连接串都是可选：有 URL 就显示 URL 行，有连接串就显示连接块，都填就两组都显示（如 Harbor/Vault 既有域名又有 API 端点）。
只填 kind/name/env 不填任何地址 → 纯元数据卡（如 K8s 集群）。同名双环境自动聚合。点右上「+ 新增资源」可体验。
